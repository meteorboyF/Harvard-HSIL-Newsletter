# Harvard HSIL Hackathon – Bangladesh Hub Newsletter

Sponsor newsletter for the Harvard HSIL Hackathon Bangladesh Hub, hosted by IRIIC, United International University.

- `index.html` – web version (GitHub Pages: https://meteorboyf.github.io/Harvard-HSIL-Newsletter/)
- `email.html` – email version with absolute image URLs. Open it in a browser, select all, copy and paste into Gmail/Outlook, or import it into your mail tool.
- `HSIL_Hackathon_2026_Dhaka_Hub_Report.pdf` – the 2026 hub report linked from the newsletter.
